scripted · no AI · no advisor
This endpoint is a scripted deterministic demo. It does NOT use OpenAI and does NOT involve a real advisor.

  • Useful for validating the deterministic pipeline: governance → suitability → ESG → data quality → optimizer, plus SQLite persistence, audit trail and Markdown report.

AI Universe Filter Demo — POST /ai/filter-universe-demo

OpenAI + universe · no persist
Requiere OPENAI_API_KEY en la terminal donde corre uvicorn.
  • Paso 1 — la IA (OpenAI) extrae preferencias estructuradas desde texto libre.
  • Paso 2 — PreferenceFilterEngine aplica esas preferencias al CSV del universo de instrumentos.
  • Devuelve: instrumentos elegibles, excluidos con razones, filtros aplicados y warnings.
  • No genera portfolios. No trae datos de mercado. No persiste resultados.
  • No aprueba ningún perfil — solo el asesor puede hacerlo.
  • Universo: tests/fixtures/universe/sample_instrument_universe.csv (20 instrumentos).

AI Filtered Portfolio Demo — POST /ai/filtered-portfolio-demo

OpenAI + universe + portfolio · no persist
Requiere OPENAI_API_KEY en la terminal donde corre uvicorn.
  • Paso 1 — la IA (OpenAI) extrae preferencias estructuradas desde texto libre del cliente.
  • Paso 2 — PreferenceFilterEngine filtra el universo CSV con esas preferencias.
  • Paso 3 — InstrumentMarketDataAdapter convierte los elegibles a snapshots de mercado.
  • Paso 4 — ReturnEstimator + CovarianceEngine + PortfolioGenerationCoordinator generan hasta 3 variantes (DEFENSIVE / BALANCED / GROWTH).
  • Si el universo filtrado es insuficiente o no es factible, devuelve el motivo del bloqueo sin generar portfolios.
  • No persiste resultados. No aprueba ningún perfil. Solo para demo.
  • Universo: tests/fixtures/universe/sample_instrument_universe.csv (20 instrumentos).
